## *✨ Sobre el proyecto*

**SudoKlar** es una aplicación web interactiva para jugar, validar y resolver sudokus de **9 × 9**. Esta entrega lleva el proyecto de JavaScript nativo a **React**, conservando sus funciones y sumando una interfaz clara, adaptable y fácil de usar.

> *Nueve números, un tablero y una pausa para pensar.* 💚

## *🎲 Funcionalidades*

- 🧩 **Juega** en un tablero interactivo; las pistas iniciales están protegidas.
- 🌱 **Genera retos** tranquilos, intermedios o desafiantes, con solución única.
- 🧠 **Resuelve el tablero** con un algoritmo de backtracking.
- 💡 **Pide una pista** para descubrir una casilla correcta.
- ✅ **Detecta conflictos** en filas, columnas y cuadros de 3 × 3.
- ⌨️ **Navega con las flechas** y captura números del 1 al 9.
- ⏱️ **Mide tu tiempo** y conserva récords por dificultad.
- 💾 **Guarda el progreso automáticamente** en el navegador.
- 📱 Disfruta un diseño **adaptable a móvil y computadora**.

## *🚀 Cómo ejecutarlo*

Necesitas **Node.js 20 o posterior** y npm.

```bash
cd react-rjss-solver
npm install
npm run dev
```

***Abre la dirección local indicada por Vite, normalmente [`http://localhost:5173`](http://localhost:5173).***

### *🧪 Pruebas y compilación*

```bash
npm test       # Ejecutar las pruebas del solver y el generador
npm run build  # Crear la versión de producción en dist
```
